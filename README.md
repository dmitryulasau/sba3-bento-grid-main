# Bento Grid

### Frontend Mentor challenge link: [here](https://www.frontendmentor.io/challenges/bento-grid-RMydElrlOj)

## Overview

This is my solution to the Bento Grid challenge from Frontend Mentor. I built a responsive layout using HTML, CSS, and Bootstrap.

## My Approach

I used Bootstrap for the grid layout and custom CSS for styling. I also used Figma as a reference, which helped me a lot with card sizes, spacing, colors, and positioning.

## Challenges & What I Learned

The most challenging part was matching the original design while keeping everything responsive. I worked through it step by step, adjusting the layout, card sizes, and spacing.

This project helped me improve my CSS Grid and responsive design skills and gave me more practice turning a Figma design into a working webpage.
